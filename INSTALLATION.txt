CORRECTION MODÉRATION / MODIFICATION DES OFFRES

1. Sauvegardez les 7 fichiers concernés avant remplacement.
2. Copiez src/, templates/ et public/ à la racine du projet en conservant les chemins.
   Fusionnez les dossiers ; ne supprimez pas vos dossiers existants.
3. Exécutez avec le PHP du projet :
   php bin/console cache:clear --env=prod
4. Rechargez avec Ctrl+F5.
Aucune migration SQL.

APRÈS INSTALLATION
Approuvez une offre valide puis consultez la liste publique sans filtre.
Une offre ancienne peut se trouver sur une page ultérieure selon le tri.
Approuvez une offre expirée avec une nouvelle date et vérifiez sa présence.
Modifiez une offre, testez un champ vide puis une saisie correcte, et rouvrez pour vérifier.
Si la profession a été supprimée, choisissez une profession existante avant d'enregistrer.
Le statut PUBLIÉE (ou PUBLIE/PUBLIEE/PUBLISHED) doit exister dans la table des statuts.
