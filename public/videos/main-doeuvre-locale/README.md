# Vidéos éditoriales - Main d’Œuvre Locale

Les templates sont déjà reliés à ces fichiers. Déposez les exports finaux dans ce dossier en conservant exactement les noms ci-dessous.

## 1. HERO silencieux - page d’accueil
- `hero-loop.mp4`
- `hero-loop.webm` (recommandé pour accélérer le chargement)
- Durée cible : 45 à 60 secondes
- Obligatoire : sans piste audio, `muted`, boucle fluide, plans ralentis, format paysage 16:9
- Contenu : réveil de la ville puis professionnels en activité, avec très peu de texte incrusté

## 2. Présentation de la fondatrice / origine
- `founder-origin-fr.mp4` et/ou `founder-origin-fr.webm`
- `founder-origin-en.mp4` et/ou `founder-origin-en.webm`
- Durée maximale : 1 min 30 s
- Page : Notre histoire

## 3. Explication des fonctionnalités
- `features-fr.mp4` et/ou `features-fr.webm`
- `features-en.mp4` et/ou `features-en.webm`
- Durée cible : environ 2 minutes
- Page : Nos services

## 4. Nécessité / impact / témoignages
- `impact-testimonials-fr.mp4` et/ou `impact-testimonials-fr.webm`
- `impact-testimonials-en.mp4` et/ou `impact-testimonials-en.webm`
- Durée cible : environ 1 minute
- Emplacement : page d’accueil

## Recommandations web
- MP4 : codec H.264, audio AAC uniquement pour les vidéos avec voix
- WebM : VP9 ou AV1
- Résolution : 1920x1080, avec version mobile possible en 1280x720
- Débit conseillé : 2,5 à 5 Mbit/s pour MP4
- Ajouter des sous-titres FR/EN (`.vtt`) lors de la livraison finale
- Garder les affiches/posters déjà configurées dans les templates jusqu’à réception des visuels officiels
